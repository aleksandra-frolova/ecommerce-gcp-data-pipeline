# Project Setup

**Create virtual environment in Visual Studio Code**

Virtual environment helps to avoid future conflicts related to program versions.

`python3 -m venv venv`

`source venv/bin/activate`

**Google Cloud Storage (GCS)**
- GCS was created with default settings
  - Was chosen the closest region europe-west3. The goal is to keep the GCS bucket and data fusion pipeline in one region to avoid slow cross-region data transfer and charges.
  - Storage class: Standard. No retrival fees, but the highest price per GB. There was no plan to store data for long time.
  - Acess Control: Uniform. Permissions are set at the bucket level - every object in the bucket inherits the same access rules.
- Service account was created
  - Given roles: BigQuery Job User, Cloud Data Fusion Runner, Dataproc Worker, Storage Admin
- Authentication for GCS through terminal
  - https://cloud.google.com/sdk/docs/install -install the official google cloud SDK installer directly
    - Unzip
    - `./google-cloud-sdk/install.sh` -run
    - Add to PATH
  - `gcloud auth application-default login` -log in
  - `gcloud config set project YOUR_PROJECT_ID` -set the project
    - `gcloud projects list` -to find project ID
- Install GCS library: `pip install google-cloud-storage`

**Data Fusion**
- Create Data Fusion Instance with default settings
  - Set the same region: europe-west3

**Big Query**

- Create dataset
  - Set the same location: europe-west3
- Manage access within this specific dataset. Share it with service account and grant role BigQuery Data Editor.


# Project Steps
**generate_data.py**
- `pip install faker` -type the command in the terminal
- `python generate_data.py`

**upload_to_gcs.py**
- `python upload_to_gcs.py`

The folder with data will appear in GCS.

**Data Fusion**

The pipeline was built: GCS -> Wrangler -> BigQuery
The data was reviewed and was found that column "order_date" has inconsistent dates. Data Fusion doesn't have capabilities to easy fix the issue, so was decided to write a python function for that.

The file "transform_order_date.py" was created where the issue with date was fixed. Data were uploaded to GCS again and went through wrangler to parse schema correctly and after were uploaded to BigQuery. This last step was applied on other data too. So it means all three tables: customers.csv, orders.csv, products.csv were uploaded to BigQuery.

**BigQuery**
There was notices inconsistency in customer table column "country". There were values like "US", "USA" etc. I decided to clean data inside big query and create golden layer where all data is consistent.
